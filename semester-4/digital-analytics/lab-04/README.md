# Telegram-бот с классификацией изображений — лабораторная 4

Цифровая аналитика, 4 семестр. Бот принимает фото и определяет один из двух классов: человек или лошадь. Для классификации используется ResNet-18 из [третьей лабораторной](../lab-03).

## Запуск

Нужен Python 3.10 или новее. Создайте и активируйте виртуальное окружение, затем из этой папки выполните:

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните `TOKEN` новым токеном из BotFather. Файл `.env` не должен попадать в Git. Веса по умолчанию берутся из `../lab-03/weights.pth`; другой путь можно задать переменной `WEIGHTS_PATH`.

```bash
python lab4.py
```

По умолчанию используется long polling. В личном чате с ботом:

1. `/register <пароль>` — регистрация, от 8 до 256 символов;
2. `/login <пароль>` — вход;
3. фото с подписью `/predict` — классификация;
4. `/logout` — завершение сессии.

Для бота используйте отдельный пароль: команды остаются в переписке Telegram. Регистрации сохраняются в `data/users.db` с хешами scrypt. Сессия действует 30 минут и завершается при перезапуске; после пяти неудачных попыток входа действует ограничение на минуту. Реализация рассчитана на один процесс бота.

## Webhook

Режим нужен только при наличии своего HTTPS-адреса или туннеля. Задайте `WEBHOOK_URL` и отдельный случайный `WEBHOOK_SECRET`, затем выполните:

```bash
python lab4.py --mode webhook
```

Адрес webhook — `/webhook`. Входящие обновления проверяются по заголовку `X-Telegram-Bot-Api-Secret-Token`. Локальный Flask-сервер слушает `127.0.0.1:8080`; наружный HTTPS организуется отдельно. Для обычной демонстрации достаточно polling.

Фото ограничены 8 MiB и 16 мегапикселями. Модель загружается один раз; файлы весов читаются с `weights_only=True`. Распознавание ограничено обученными классами и может ошибаться на других объектах.

Проверки регистрации, входа, webhook и inference с готовыми весами выполняются без обращения к Telegram:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```
