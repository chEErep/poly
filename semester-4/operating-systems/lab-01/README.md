# SolverOS — лабораторная 1

Операционные системы, 4 семестр. Учебное 32-битное ядро x86: загрузочный сектор с выбором цвета, переход в protected mode, вывод в VGA-память и ввод с клавиатуры через IRQ1.

Команды:

- `info` — сведения о системе и выбранном цвете;
- `gcd 48 18` — наибольший общий делитель положительных целых чисел;
- `solve 2x+1=4` — решение линейного уравнения, здесь `x=3/2`;
- `shutdown` — выключение QEMU.

Числа проверяются на переполнение 32-битного `int`, командная строка ограничена 40 символами. Это минимальное учебное ядро без файловой системы, процессов и полноценной обработки исключений процессора.

## Сборка и запуск

Сборка использует Clang с поддержкой MS-style inline assembly, LLD, NASM и Python 3. В Linux после установки этих инструментов выполните `sh build.sh`.

Для Windows удобнее собрать через Docker из этой папки (PowerShell):

```powershell
docker build -t solveros-build .
docker run --rm -v "${PWD}:/src" solveros-build sh build.sh
```

Получится `build/solveros.img`. В QEMU:

```bash
qemu-system-i386 -drive file=build/solveros.img,format=raw,if=floppy
```

Выберите цвет стрелками и нажмите Enter. Загрузчик читает ядро с того диска, с которого был запущен, и загружает его в `0x11000`. Скрипт сборки размещает секции PE и нулевую область данных в образе; размер ядра ограничен 64 секторами. `start.asm` оставлен как первый вариант загрузочного сектора с выводом Hello, основная сборка использует `bootsect.asm`.
