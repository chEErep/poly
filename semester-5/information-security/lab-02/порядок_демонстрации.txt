👓 Порядок демонстрации лабораторной №2 (50% успеха)
Необходимо выполнить следующую последовательность шагов, демонстрирующих работоспособность сервиса под ОС Windows:
1. Установка сервиса:
    1. Показываете список сервисов Windows в оснастке "Службы" и демонстрируете, что вашего сервиса в списке нет.
    2. Из командной строки вашей программы устанавливаете сервис в систему.
    3. Показываете в списке оснастки "Службы", что сервис существует.
2. Демонстрируете свой конфигурационный файл, в котором должны быть указаны:
    1. Директория, из которой бэкапить файл.
    2. Директория, в которой должен создаваться бэкап.
    3. НЕСКОЛЬКО масок с использованием * и ? так, чтобы часть файлов попадали под них, часть нет.
    4. Создаете директорию, из которой бэкапить файл. В директории создаете файлы в директории вложенности 3 (папка1/папка2/папка3). В каждой папке создаете файлы различных расширений: docx, exe, txt.
3. Запускаете сервис из вашего консольного приложения.
4. Демонстрируете работоспособность архиватора:
    1. Показываете, что создался ZIP-файл.
    2. Редактируете любой docx/txt-файл.
    3. Добавляете новый файл.
    4. Показываете, что архив обновился (именно обновился, а не создался новый) с учетом вложенности папок.
5. Демонстрируете возможность работы с архивом:
    1. БЕЗ ОСТАНОВКИ СЕРВИСА открываете встроенным в Windows просмотрщиком ZIP-файлов
    2. запускаете любой EXE-файл из архива и демонстрируете, что все работает.
6. Остановка и удаление сервиса:
    1. Останавливаете сервис из оснастки "Службы"
    2. Удаляете сервис из консоли вашего приложения
    3. Показываете, что в оснастке "Службы" вашего сервиса больше нет.
