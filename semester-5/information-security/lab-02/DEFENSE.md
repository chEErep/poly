# Краткое повторение перед защитой лабораторной 2

Полная речь и все ответы: DEFENSE_SPEECH.md. Команды показа: FIRST_SHOW.md.

## Что сделано

Служба Windows для резервного копирования выбранных файлов в ZIP и собственный SCP.
Настройки backup.ini: source, archive, mask, interval_seconds. При запуске - первая
копия, затем периодическая проверка и автоматическое обновление того же ZIP,
включая подпапки. Без различий архив не переписывается. Все девять требований реализованы.

## Три роли

- SCP просит установить, запустить, остановить, удалить регистрацию.
- SCM - системный менеджер, принимает запросы и запускает службу.
- Служба выполняет полезную работу: проверяет файлы и сохраняет ZIP.

## UNC RPC сервер

UNC - формат пути \\сервер\общий_ресурс\папка\файл. localhost - сама виртуалка,
C$ - административный ресурс C. Права всё равно проверяются.
RPC - вызов процедуры в другом процессе с передачей параметров и результата.
SCM является RPC-сервером; свой RPC мы не писали.
Сервер обрабатывает запросы клиентов. Это роль программы, также так называют компьютер.
В доступе к общим файлам используется SMB. UNC - адрес, RPC - механизм вызовов.

## Маски

* - любое число символов, включая ноль; ? - ровно один.
report_1.docx подходит под report_?.docx, report_12.docx не подходит.
Выбор по имени, не по фактическому формату. Несколько правил - ИЛИ.

## Автоматическое обновление

Проверяются имена, размеры и содержимое файлов в сравнении с ZIP. При различиях
создаётся временный полный ZIP, затем он заменяет основной по прежнему пути.
Истории версий нет, удалённые исходные файлы исчезают из актуального снимка.
При блокировке - RETRY и повторная попытка; прежняя копия сохраняется.
Пауза по умолчанию 2 секунды плюс время проверки/записи. Настройки - после перезапуска.

## Что показать

Установка -> настройки и подпапки -> запуск -> свежий Backup ready -> ZIP ->
изменить исходный TXT и добавить новый на третьем уровне -> Backup updated ->
показать данные в том же ZIP без перезапуска -> извлечь/запустить demo.exe ->
перезапуск и остановка через «Службы» -> свой stop -> удаление регистрации.

## Что не перепутать

- Install регистрирует, start запускает, stop останавливает, remove удаляет регистрацию.
- Start без install не работает. Закрытие PowerShell службу не остановит.
- RUNNING - состояние службы, готовность копии подтверждают журнал и ZIP.
- Interrogate и периодическая проверка файлов - разные операции.
- Окно demo.exe принадлежит тестовой программе; служба его не создаёт.
- Остановка службы не завершает отдельно запущенный demo.exe.
- ZIP без шифрования; VSS и история версий отсутствуют.
