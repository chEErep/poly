# Лабораторная работа № 1 — алгоритмы Евклида

Дисциплина: «Теоретико-числовые методы в криптографии». Вариант 60.

## Что делает программа

Программа берёт три пары больших положительных чисел из раздела «Задание №1» [файла варианта 60](materials/2026_var60.txt). Те же числа записаны в начале `lab1.py`. Для каждой пары она находит наибольший общий делитель (НОД) и два коэффициента Безу — числа `x` и `y`, для которых выполняется:

```text
a × x + b × y = НОД(a, b)
```

Например, для `a = 30` и `b = 18` НОД равен `6`, а одна из подходящих пар коэффициентов — `x = −1`, `y = 2`, потому что `30 × (−1) + 18 × 2 = 6`. Такие коэффициенты используются, в частности, при поиске обратного элемента по модулю, если числа взаимно просты.

Одна и та же задача решается тремя способами, чтобы сравнить их шаги и время работы:

| Метод | Основная идея |
| --- | --- |
| Расширенный алгоритм Евклида | Последовательно делит числа с остатком и одновременно пересчитывает коэффициенты Безу. |
| Расширенный бинарный алгоритм Евклида | Заменяет деление с остатком делением на 2 и вычитанием. |
| Алгоритм с усечёнными остатками | Выбирает остаток с наименьшим абсолютным значением; он может быть отрицательным. |

Для третьего метода здесь принято именно определение через *наименьший по модулю остаток*. В предоставленных лекциях отдельного определения расширенного метода нет; если преподаватель задаёт другой смысл «усечённых остатков», эту часть реализации нужно сверить с его указаниями.

## Как запустить

Нужен Python 3.10 или новее. Для вычислений и тестов дополнительные пакеты не требуются. В PowerShell перейдите в эту папку из корня репозитория и выполните:

```powershell
cd number-theory-cryptography/lab-01
py -3 lab1.py
```

Программа выводит исходные числа, НОД, коэффициенты `x` и `y`, проверку равенства Безу и журнал шагов. Если строк журнала больше двадцати, показываются первые пять и последние пять; номера шагов при этом сохраняются. В строке журнала `r` — текущий остаток, а `x` и `y` удовлетворяют равенству `a × x + b × y = r`. У бинарного метода в колонке `r` показан изменённый на данном шаге рабочий остаток.

Дополнительные режимы:

```powershell
py -3 lab1.py --full
py -3 lab1.py --benchmark
py -3 lab1.py --check
```

Первая команда показывает **все** строки шагов, вторая измеряет время каждого алгоритма, третья запускает дополнительные проверки. Время зависит от компьютера и его текущей нагрузки, поэтому при повторном запуске значения могут отличаться. На Linux и macOS вместо `py -3` обычно используется `python3`.

## Как убедиться, что ответ верный

```powershell
py -3 lab1.py --check
```

Тесты сравнивают НОД с `math.gcd`, проверяют равенство Безу для итоговых коэффициентов и для **каждой** строки журнала. Проверяются все три пары варианта в обоих порядках, небольшие граничные случаи, сто случайных пар и некорректный ввод. Функции принимают только положительные целые числа; ноль, отрицательные числа, `bool` и другие типы отклоняются.

Коэффициенты, найденные разными методами, могут быть разными — это не ошибка. Если `(x, y)` является одним решением, то остальные имеют вид `x′ = x + (b/d)k`, `y′ = y − (a/d)k`, где `d = НОД(a, b)`, а `k` — целое число.

## Как устроен файл

В [`lab1.py`](lab1.py) сначала записаны числа варианта, затем функции трёх алгоритмов. Каждая возвращает пять значений: `НОД`, `x`, `y`, число основных операций и журнал шагов. Функция `main()` вызывает алгоритмы и печатает результат. Проверки и измерение времени находятся внизу того же файла; для обычного запуска их разбирать не обязательно.
