# poly

Репозиторий с моими университетскими лабораторными работами, учебными проектами и техническими экспериментами.

Здесь хранятся материалы по программированию, информационной безопасности, сетям, криптографии и другим направлениям, которые изучаю в университете.



## Структура репозитория

```text
poly/
├── semester-4/
│   ├── digital-analytics/
│   └── operating-systems/
├── semester-5/
│   ├── oop/
│   ├── information-security/
│   ├── reverse-engineering/
│   └── cryptography/
├── semester-6/
└── ...
```

[Работы четвёртого семестра](semester-4) включают классификацию изображений, Telegram-бота, учебное ядро x86 и программы на WinSock.
